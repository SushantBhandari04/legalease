# 📅 Timeline User Guide

## How to Access and Use the Case Timeline

### 🎯 **Where to Find Timeline**

1. **Navigate to Dashboard**: Go to your main dashboard
2. **Select a Case**: Click on any case from your cases list
3. **Open Timeline Tab**: In the case details modal, click on the "Timeline" tab

### 📋 **What You'll See**

#### **Automatic Timeline Events**
When you create a new case, the system automatically generates initial timeline events based on:
- **Case Filing Date**: "Case Filed" event
- **Next Hearing Date**: "Next Hearing Scheduled" event (if set)
- **Case Stage**: Additional events based on current stage

#### **Timeline Event Types**
- 🔵 **Filing**: Case filing events (blue icon)
- 🟣 **Hearing**: Court hearings (purple gavel icon)
- 🟠 **Evidence**: Evidence submission (orange file icon)
- 🟢 **Document**: Document events (green file icon)
- 🟦 **Status Change**: Stage/status changes (indigo alert icon)
- ⚪ **Custom**: Custom events (gray calendar icon)

#### **Event Status**
- ✅ **Completed**: Events that have already happened
- 🕐 **Scheduled**: Events planned for the future
- ⏳ **Pending**: Events waiting to be scheduled

### ➕ **How to Add Timeline Events**

#### **Method 1: From Timeline Tab**
1. Go to case details → Timeline tab
2. Click the **"Add Event"** button (top right)
3. Fill out the timeline event form:
   - **Event Title**: e.g., "First Hearing", "Evidence Submission"
   - **Event Type**: Select from dropdown (filing, hearing, evidence, etc.)
   - **Status**: Choose completed, scheduled, or pending
   - **Event Date**: Pick the date using the date picker
   - **Description**: Describe what happened or will happen
   - **Notes**: Optional additional details
4. Click **"Add Event"**

#### **Method 2: From Empty Timeline**
1. If no events exist, you'll see an empty state
2. Click **"Add First Event"** button
3. Follow the same form process as above

### 📝 **Timeline Event Form Fields**

| Field | Description | Required |
|-------|-------------|----------|
| **Event Title** | Short title for the event | ✅ Yes |
| **Event Type** | Category of the event | ✅ Yes |
| **Status** | Current status of the event | ✅ Yes |
| **Event Date** | When the event occurred/will occur | ✅ Yes |
| **Description** | Detailed description | ✅ Yes |
| **Notes** | Additional notes or details | ❌ Optional |

### 🎨 **Visual Timeline Features**

#### **Event Cards**
- **Color-coded backgrounds**: Green (completed), Blue (current), Gray (upcoming)
- **Event type badges**: Shows the category of each event
- **Date display**: Shows day and month in a compact format
- **Status icons**: Visual indicators for event status

#### **Timeline Flow**
- **Vertical line**: Connects all events chronologically
- **Chronological order**: Events sorted by date (newest first)
- **Responsive design**: Works on desktop and mobile

### 🔄 **Timeline Updates**

#### **Automatic Updates**
- Timeline refreshes when you add new events
- Events are automatically sorted by date
- Status changes are reflected immediately

#### **Real-time Data**
- All timeline data is stored in the database
- Changes are saved immediately
- Timeline persists across sessions

### 💡 **Best Practices**

#### **Event Naming**
- Use clear, descriptive titles
- Include relevant details in descriptions
- Add notes for important context

#### **Date Management**
- Use actual dates when possible
- For future events, use scheduled status
- For past events, use completed status

#### **Event Types**
- **Filing**: Use for case filing and initial submissions
- **Hearing**: Use for all court appearances
- **Evidence**: Use for evidence collection and submission
- **Document**: Use for document-related events
- **Status Change**: Use for stage or status updates
- **Custom**: Use for any other case-related events

### 🚀 **Advanced Features**

#### **Timeline Integration**
- Timeline events are linked to case data
- Automatic event generation based on case stage
- Integration with case status and progress

#### **Future Enhancements**
- Edit existing timeline events
- Delete timeline events
- Timeline event notifications
- Document attachments to events
- Timeline export functionality

### ❓ **Troubleshooting**

#### **Common Issues**
1. **"No timeline events found"**: Click "Add First Event" to get started
2. **Events not showing**: Refresh the page or check your internet connection
3. **Can't add events**: Ensure you're logged in and have permission to edit the case

#### **Getting Help**
- Check the console for any error messages
- Ensure you're using a supported browser
- Contact support if issues persist
